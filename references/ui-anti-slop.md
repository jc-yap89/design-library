# UI 去 AI 感：审计判据

本文改写并压缩自 [heydamir/unslop](https://github.com/heydamir/unslop)（Damir Sokolovsky，[@heydamir](https://x.com/heydamir)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)），已翻译、合并、删减，并加入"组件库取用"一节。上游的方向设定、配色与字体表、首屏场景生成、线上页面抓取和演示视频不在这里，需要时直接用上游技能。

## 它管什么，不管什么

**只管一件事：判断一个界面（或一个刚取来的组件）有没有"一眼看出是 AI 生成 / 模板拼出来"的套路，并给出去掉它的改法。**

不管的事交给原来的负责方：风格方向、配色、字体 → ui-ux-pro-max / design-taste-frontend / impeccable；前后对比 → site-retrofit；渲染验收 → visual-regression-acceptance。本文给它们提供"哪里算套路"的共同判据，不替它们定方向。

核心判断：**套路是把颜色和特效撒满外围元素（背景、按钮、边框、标签），好设计让外围安静，把丰富度集中到一两处内容亮点（一张用心画的图表、一个有真实质感的物体）。** 清理之后再问一次：把产品名换成别家的，这个界面还成立吗？成立，就说明只是干净的模板。

**用户偏好优先。** 用户明确说过喜欢的做法（例如"我就要渐变"）按[偏好规则](preference-memory.md)执行，本文只是默认判据；有意保留的套路在汇报里注明。

## 一、判据清单（套路 → 改法）

**颜色与表面**
- 紫→蓝、紫→粉渐变用在背景、卡片、按钮、当前导航项 → 单一中性表面，强调色只用在有含义处
- 渐变文字（标题、数字、Logo） → 纯色主文字
- 彩色发光、`drop-shadow` 套在 emoji 上、发光药丸 → 去掉，用表面层级 + 细线表现深度
- 内容后的径向色晕、模糊色块；霓虹边框 → 去掉 / 改成约 8% 透明度的细线
- 玻璃卡片（白色内高光 + 彩色阴影） → 普通抬升表面 + 细线
- 同一色相的五六种文字色；处处高亮 → 主 / 次 / 弱三档；强调色每屏只出现一两次

**字体与数字**
- 700–900 字重标题 → 400–500，靠字号分层级
- 全大写 + 大字距标签 → 句首大写
- 小字负字距、斜体强调 → 0 字距、改用颜色或字重
- 数字格式混用（`$48,210` 与 `$124,860.40`） → 统一格式 + 等宽数字

**图标**
- emoji 当导航图标、标签装饰、状态；药丸里放 emoji → 同一套线性图标（同尺寸、同描边、取文字层级色）或不放
- ✨ 表示"AI"、机器人、发光大脑、电路线 → 去掉，除非它真的说明了什么

**间距**
- 任意值（`mt-[13px]`）、同一列表行高不一、同级卡片内边距不一 → 回到 4px 阶梯，同类同尺寸
- 组内间距比组间大 → 组内小、组间大

**文案**
- 问候标题（`Welcome back! 👋`）、感叹号 → 用页面名或时间范围；陈述句
- 变化量没有参照（`+12%!!`） → `较上月 +12%`
- `Search anything...` 这类啰嗦占位 → `搜索`
- supercharge / seamless / unlock / magic，"赋能""一键解锁" → 写它实际做了什么
- 标签和按钮末尾带句号；`[X]`、`$123,456` 式假数据 → 去句号；用可信的具体数字
- `10,000+ 团队信赖`、五星、头像点没有出处 → 先问是否属实，属实则具体克制，否则删除

**组件**
- 发光药丸表示计数 / 状态 / 快捷键；到处 `PRO` `New ✨` `Beta 🚀` → 弱化文字、键帽样式；去掉
- 所有元素都是全圆角 → 按尺寸定圆角，嵌套圆角：内 = 外 − 间距（最小 4）
- 图表彩虹柱、发光柱、大写星期标签 → 一个系列一个高亮色，其余中性，弱网格 + 等宽弱色标签
- 统计卡都带迷你折线 / 小柱；并排等宽等内容的卡片 → 统计卡只留标签、数字、变化量；一个主图表 + 紧凑指标 + 宽窄变化
- Logo 是渐变方块 / 星芒 / 玻璃球 → 产品名文字 + 简单纯色标记

**落地页首屏**
- 标题上方药丸徽章（`✨ Introducing X 2.0`）；放任何产品都成立的标题 → 去掉；写产品为谁做什么
- 渐变或流光标题；后方漂浮色块、球体、发光网格线 → 纯色标题；纯背景或一个真实产品画面
- 全部居中堆叠；三个以上按钮 → 不对称分栏或文字压在大产品画面上；一个主操作 + 至多一个次操作
- 3D 光泽团块、液态金属、星云、机器人、全息图当主视觉；图里烘焙文字；每区块都配图 → 展示产品本身；文字放页面里；通常只首屏配一张

**动效**
- 非"实时"元素的 `animate-pulse` / `animate-ping` / 呼吸发光；视差、漂浮 → 静态
- `transition-all`、卡片 `hover:scale`、弹簧过冲 → 只过渡 color / background / border / opacity / transform；悬停变色，按下轻微缩小
- 加载时各元素从不同方向飞入 → 一次短促淡入上浮，轻微错峰
- 动画 width / height / top / left → 改 transform 和 opacity

**模板化回退**（不算套路，但清理后最容易退回）
- 纯灰底 + Inter + 白字 + 旧品牌色按钮，无论产品是什么 → 让色阶和强调色偏向产品的世界
- 换个产品名也成立的标题；首屏视觉是空框或通用图 → 写产品自己的名词；做产品预览

## 二、可量化的底线（判据，不是风格规范）

- 间距值在 4 的倍数上（控件内的 2px 微调除外）
- 字重 400–500，强调最多 600；小字（< 16px）字距不为负
- 强调色上的文字对比度 ≥ 4.5:1；弱文字约 4.5:1
- 细线 = 主文字色约 6–10% 透明度
- 动画只用 transform / opacity；全局一条缓动曲线；悬停 120–180ms，入场 300–500ms
- 数字使用 `tabular-nums` 且格式统一
- 一个图表一个强调色；一屏一个主图表

## 三、取用组件库时的套路来源

这个技能的主要工作是"先查再复用"，而被检索的库本身是套路的主要来源，不是中立货架。本目录的粗略统计（名称或标签含 gradient、glow、neon、glass、liquid、aurora、spotlight、blob 等词）：3,788 条里约 434 条（11.5%），Uiverse 约 15%（291/1,956），Magic UI 约 14%，Originkit 约 8%，Aceternity 约 7%，Kokonut UI 约 4%。这只说明哪里需要多检查一眼，不代表质量差，也不代表用户不能要。

| 常带入的东西 | 取用时怎么处理 |
|---|---|
| 色相渐变、渐变文字、发光、彩色阴影 | 参数里换成产品的中性色阶 + 一个强调色；确认用户真要才保留，并只用在一个亮点上 |
| `transition-all`、弹簧、`hover:scale`、循环脉冲 | 改成只动 transform / opacity，缩短时长，去掉无意义的循环 |
| 全圆角、药丸、玻璃拟态 | 按尺寸重定圆角；玻璃卡片改普通抬升表面 |
| 示例文案（"Supercharge…"、假好评、假数据） | 全部换成产品自己的真实文案 |
| 名称带 Sparkles / Blob / Aurora / Orb 的装饰与背景 | 先问"它在说明产品的什么"；说明不了就换掉或不用 |
| AI 产品组件里的 ✨、渐变"AI"按钮、发光球 | AI 产品同样要去 AI 感；✨ 只留在真正说明"AI 生成 / 建议"的地方 |

规则很简单：**搬进来的组件，视觉层按本文改一遍再算完成**，与 SKILL.md 里"复用后必须改"一致。

## 四、交付前检查

- [ ] 无色相渐变、渐变文字、发光、彩色阴影、色晕
- [ ] 界面里没有 emoji；同一套图标、同一尺寸和描边
- [ ] 一条带色调的中性色阶、三档文字色、一个对比度足够的强调色
- [ ] 间距在 4px 阶梯上，同类元素同尺寸，嵌套圆角成立
- [ ] 字重 400–600，无大写大字距标签，数字格式统一且等宽
- [ ] 无感叹号、无问候标题、无未证实的宣称、无假数据
- [ ] 无循环或弹跳动效，不动画布局属性，有悬停和焦点状态
- [ ] 取来的组件已换掉示例文案、色值和动效参数
- [ ] 模板检验：换成别家产品名，界面还成立吗？成立就继续往产品本身推
- [ ] 与已记录的用户偏好无冲突；有意保留的套路已在汇报中注明
