# UI 去 AI 感：审计清单与默认值

本文改写并压缩自 [heydamir/unslop](https://github.com/heydamir/unslop)，作者 Damir Sokolovsky（[@heydamir](https://x.com/heydamir)），许可 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。已翻译、删减、合并，并增加了与本技能偏好机制的衔接规则；上游完整流程、视觉生成、线上页面抓取和演示视频脚本不在此处，需要时直接用上游技能。转载或再改编请保留此署名与链接。

核心判断：**AI 味来自把颜色和特效撒满外围元素（背景、按钮、边框、标签），而不是没有"内容亮点"。** 好界面让外围安静，把丰富度集中到一两处值得记住的内容上（一张精心绘制的图表、一个真实质感的物体、产品世界里的一张图）。清理完还要问一句：**把产品名换成别家的，这个界面还成立吗？成立，说明只是干净的模板，要把方向再往文案、视觉和签名细节上推。**

## 与用户偏好的关系

这是默认判断，不是禁令。用户在[偏好规则](preference-memory.md)中明确表达的偏好（例如"我就喜欢渐变"）优先于本清单；冲突时按偏好执行，并在汇报里注明该处有意保留。未经用户表态，才按本清单处理。

## 一、审计清单（逐组过一遍，每条记录位置）

**颜色与表面**
- 紫→蓝 / 紫→粉渐变用在背景、卡片、按钮、当前导航项 → 单一中性表面，强调色只用在有含义处
- 渐变文字（标题、数字、Logo） → 纯色主文字
- 彩色发光、`drop-shadow` 套在 emoji 上、发光药丸 → 去掉，用表面层级和细线表现深度
- 内容后面的径向色晕、模糊色块 → 去掉
- 霓虹或高对比彩色边框 → 8% 左右透明度的细线
- 同一色相的五六种文字色（五种淡紫） → 主 / 次 / 弱三档
- 处处高亮导致没有重点 → 每屏强调色只出现一两次
- 玻璃卡片 + 白色内高光 + 彩色阴影 → 普通抬升表面 + 细线

**字体**
- 700–900 字重标题 → 400–500，靠字号分层级
- 全大写 + 大字距标签（`NAVIGATION`） → 句首大写、正常字距
- 一屏内字号字重过多 → 少量字号 + 400/500 两档
- 数字格式混用（`$48,210` 与 `$124,860.40`） → 统一格式 + 等宽数字
- 小字负字距 → 0 或略正
- 用斜体做强调 → 改用颜色或字重

**图标**
- emoji 当导航图标、标签装饰或状态（🏠 📥 🚀 💰 ⚠️） → 同一套线性图标，或不放
- 药丸 / 计数里的 emoji（`18 👤`） → 纯数字
- 多种尺寸颜色的图标 → 一个尺寸、一个描边、取文字层级色
- ✨ 表示"AI" → 去掉，除非它真的说明了什么

**间距**
- 任意值（`mt-[13px]`、`h-[31px]`） → 回到 4px 阶梯
- 同一列表行高、间距不一 → 统一
- 组内间距反而比组间大 → 组内小、组间大
- 同级卡片内边距不一 → 统一
- 上方大片空白、下方局促 → 平衡节奏

**文案**
- 问候式标题（`Welcome back, Damir! 👋`） → 用页面名或时间范围，如 `2026 年 10 月`
- 感叹号 → 陈述句
- 变化量没有参照（`+12%!!`） → `较上月 +12%`
- 啰嗦占位（`Search anything...`） → `搜索`
- 夸张词（supercharge、seamless、unlock、magic、revolutionize、game-changing，以及"赋能""一键解锁"之类） → 写它实际做了什么
- 标签、按钮末尾带句号 → 去掉（多句段落保留）
- 假数据（`$123,456`、`[X]`） → 可信的具体数字

**组件**
- 发光药丸表示计数、套餐、快捷键、状态 → 弱化的等宽文字或键帽样式
- 到处 `PRO`、`New ✨`、`Beta 🚀` → 去掉，或只留一个安静的文字徽标
- 所有元素都是全圆角 → 按尺寸定圆角，用嵌套圆角算法
- 图表彩虹柱、发光柱、药丸柱、大写星期标签 → 一两个系列，弱网格、等宽弱色标签、一个高亮色
- 每个统计卡都带迷你折线 / 小柱 → 只留标签、数字、变化量
- 并排等宽等内容的卡片 → 一个主图表 + 紧凑指标 + 宽窄变化
- Logo 是渐变方块 + 星芒 + 渐变字标 → 产品名文字 + 简单纯色标记
- Logo 是玻璃球 / 渐变球 / 发光点 → 纯色符号或只用字标

**落地页与首屏**
- 标题上方药丸徽章（`✨ Introducing X 2.0`） → 去掉；确有新闻可改为安静文字链接
- 放在任何产品上都成立的标题（"用 AI 赋能你的工作流"） → 说明产品为谁做什么
- 标题渐变或流光 → 纯色
- 首屏后方漂浮色块、球体、发光网格线 → 纯背景或一个真实产品画面
- 全部居中堆叠（标题、段落、按钮、下方一张图） → 不对称左右分栏，或文字压在大尺寸产品画面上
- 三个以上按钮，或按钮下又堆芯片和头像 → 一个主操作 + 最多一个次操作
- `10,000+ 团队信赖`、一排头像点、五星没有出处 → 先问是否属实，属实则具体而克制，否则删除
- 视差、滚动漂浮元素 → 静态布局
- 功能卡 = emoji + 粗标题 + 一句空话 → 减少数量、写具体、线性图标或不放

**视觉素材**
- 3D 光泽团块、球体、液态金属、紫色星云当首屏主视觉 → 产品本身或一个具体隐喻
- 机器人、发光大脑、电路线、全息图代表"AI" → 去掉，或展示 AI 真正产出的东西
- 文字、假按钮、假 Logo 烘焙在图里 → 文字放在页面里，图不带字
- 图与页面不融合（硬边、黑色深浅不同） → 背景色对齐页面并做边缘柔化
- 每个区块都配图 → 通常只在首屏配一张

**动效**
- 非"实时"元素用 `animate-pulse` / `animate-ping` / 呼吸发光 → 静态
- `transition-all`、卡片 `hover:scale` → 颜色或表面层级变化，按下时轻微缩小
- 简单 UI 上的弹簧、过冲 → 一条 ease-out 曲线
- 加载时各元素从不同方向飞入 → 一次短促的淡入上浮，轻微错峰
- 动画 width / height / top / left → 只动 transform 和 opacity

**模板化回退**（不算 AI 味，但清理后最容易退回的样子）
- 纯灰 #161616 + Inter + 白字 + 旧品牌色按钮，用在世界观偏暖或明亮的产品上 → 偏向该世界的色阶和强调色
- 换个产品名也成立的标题 → 用这个产品自己的名词
- 首屏视觉是空框或通用图片 → 用代码做产品预览，或来自产品世界的图
- 所有产品同一套布局、字体、配色 → 让方向来决定

## 二、先定方向，再动手

修改前用五行写清楚，必须从产品本身推出，而不是从流行趋势推出。有明确偏好记录时，方向要与之一致。

- **产品**：做什么、给谁，一句话。
- **性格**：两三个具体词（如"冷静、精确、略带温度"）。不要用 clean、modern、sleek、minimal、premium、简洁、现代、高级，它们适用于任何模板。
- **世界**：产品天然所处的材质或场景（笔记 → 纸与墨；监控 → 仪表与夜班；旅行 → 地图与窗光）。它决定中性色的色调、强调色和视觉。
- **亮点**：一两处允许丰富色彩和材质的位置，选自产品会展示的内容。
- **签名细节**：只有这个产品才有的一个小细节，全程一致使用（监控的实时状态点、开发工具的键帽、教学应用的手绘下划线）。

产品已有真实品牌（Logo、品牌色、非套路字体）就保留并围绕它。紫蓝渐变、星芒、发光即使在 Logo 里也算套路，除非用户明确说是品牌。

## 三、修改顺序

**间距 → 颜色 → 图标 → 文案 → 字体 → 布局 → 细节 → 视觉 → 动效。** 每一遍跨整个界面做完再进入下一遍。间距先行，因为节奏对了其余才看得清；文案先于字体和布局，因为标题长度决定字号和位置；视觉和动效最后，应当落在一个没有它们也成立的界面上。

按程度分三档：
- **重度**（颜色、字体、图标、文案多处命中）：走完整流程。
- **轻度**（基本已设计过，剩几处）：只修审计出的问题，沿用现有品牌的方向、配色、字体、布局；更大的想法写进汇报当建议，不直接改。
- **没问题**：直接说没问题，最多给两三条带具体数值的小建议，经同意再改。不要为了不同而改动好界面。

定好方向后，若用户没说"直接做"，先把审计和方向给用户确认再改，因为中途换方向等于重做。

## 四、默认数值（起点，不是风格强制；项目已有好体系就沿用）

**间距**：阶梯 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 / 80 / 96 / 128。控件内 4–12；相关项（列表行）2–8；组与组 12–24；区块间 32–64，落地页区块 80–128。行高 32 紧凑 / 36 默认 / 40–44 触控。首屏导航到标题 96–128（移动端 48–64）。

**应用布局**：侧栏 240–280，内容区流式，页边距 24–32，最大宽度约 1440–1600；顶栏 56–64；导航行 32–36、行距 2–4，分区标签上方 24 下方 8。同行统计卡等高，桌面一行 3–4 张，只放数字。主图表占内容区至少三分之二宽、高 280–360，旁边是列表或表格而不是第二个图表。不要把应用缩成居中的窄栏。

**中性色阶（深色，石墨 / 暖 / 墨蓝）**

| 角色 | 石墨 | 暖 | 墨蓝 |
|---|---|---|---|
| 最深（侧栏） | #0f0f10 | #12110f | #07080d |
| 页面背景 | #141415 | #161513 | #0b0d14 |
| 卡片 | #19191b | #1c1a18 | #11141c |
| 抬升（选中行、输入框） | #232325 | #262421 | #1a1e28 |
| 主文字 | #ededed | #efe9de | #eef0f5 |
| 次文字 | #a1a1a6 | #aaa398 | #a3a9b8 |
| 弱文字 / 图标 | #85858b | #8a847a | #7a8296 |

浅色：页面 #fafafa / #f7f4ee / #f5f7fa，卡片 #ffffff / #fdfbf7 / #ffffff，抬升 #f4f4f5 / #efe9df / #eceff4，主文字 #171717 / #1f1b16 / #111827。细线统一取主文字色 8% 透明度。应用和仪表盘的表面保持石墨或同样的灰；落地页可按世界观选暖或墨蓝。弱文字只用于说明性小字，对比度保持约 4.5:1。语义色：正向 #4cc38a（深）/ #16a34a（浅），负向 #e5484d / #dc2626。

**强调色**：保留真实品牌色；没有就取自世界（暖 → 琥珀 / 珊瑚；冷 → 钴蓝 / 青；自然 → 苔绿 / 鼠尾草），回避紫蓝家族。强调色上的文字对比度 ≥ 4.5:1，不够就加深强调色或改用深色文字。强调色只占屏幕几个百分点：主操作、当前选中、一个关键数字。深色主题的主按钮可用色阶里的近白底 + 深字。

**按钮**：首屏 44–48 高，导航 32–36，左右内边距 16–20。次按钮 = 抬升表面 + 细线。深色按钮可加 `inset 0 1px 0 rgba(255,255,255,0.12)` 的顶部高光。

**字体**：精确 / 技术 / 冷静 → Geist、Inter、IBM Plex Sans，搭配 Geist Mono / JetBrains Mono 用于数字与元信息；温暖 / 友好 → Instrument Sans、DM Sans、Figtree，首屏标题可配 Instrument Serif 或 Newsreader；编辑 / 文学 → 界面用 Inter 或 Instrument Sans，标题用 Newsreader、Instrument Serif、Fraunces；活泼 / 大胆 → Space Grotesk、Bricolage Grotesque。一个界面一套家族，最多再配一个搭档；展示衬线只用于大标题。保留项目中属于品牌的字体；没人选过的默认 Inter 可以换。中文界面的字体按平台实际可用字体另行选择。

**字号**：标签 12/16；说明 13–14/20；正文与导航 14–15/20–22；页面标题 28–36；卡片数字 28–32 且等宽；首屏标题 56–72（移动端 36–44），行高 1.02–1.08。字距：16px 以下为 0（弱色小字可略正，如 0.01em）；40px 起可到 -0.02em，56px 起 -0.03em。

**圆角**：键帽 / 标签 4–6；行 / 输入 / 按钮 8–10；卡片 12–16；面板 / 窗口 14–20。嵌套圆角：内圆角 = 外圆角 − 间距，最小 4。

**图标**：lucide，16 或 18px，描边 1.5，取弱 / 次文字色，与标签间距 8–10。

**深度**：深色靠表面层级 + 细线；浅色阴影 `0 1px 2px rgba(0,0,0,.05)`（小）/ `0 8px 24px rgba(0,0,0,.06)`（浮层）。

**动效**：全局一条曲线 `cubic-bezier(0.22, 1, 0.36, 1)`。悬停 / 按下 / 开关 120–180ms；菜单 / 弹层 160–220ms；入场 / 抽屉 / 布局变化 300–500ms；错峰 40–60ms，最多六项。上浮 6–12px，按下缩放 0.97–0.98。只过渡 color、background、border、opacity、transform，并显式写出，不用 `transition-all`。

## 五、几条关键执行规则

- **图表层级**：一个主图明显最大，用心绘制（平滑曲线、镜像对比）；其余数据展示体量更小、形态不同（排名列表、短表格），不放第二个同尺寸图表。一个图一个强调色，重点（本月、被追踪的线）用强调色，其余用色阶中性层级。图表类型按数据选：趋势 → 折线，比较 → 柱，占比 → 单条堆叠或带条列表，单一目标 → 进度条。
- **统计卡就是数字**：标签 + 大数字 + 带参照的变化。只有当对象本身就是数字所统计的东西时（已付收据旁边是已付收入），才可放真实质感的物体。
- **应用与仪表盘几乎不需要生成图**：亮点来自产品本身——精心绘制的图表、排版优美的数字、真实内容、有生命感的状态。生成图只用于空状态、引导和营销位。
- **首屏**：最强的是"场景"——一张横贯首屏的图，主体偏一侧，标题落在图里留出的安静空白处，产品画面从底部升起。没有场景图就用不对称分栏，视觉至少占一半宽；文字块与视觉垂直居中对齐；长标题左对齐，居中只用于一两行短句。导航保持安静：Logo、已有链接、一个按钮，登录是文字链接。移动端按阅读顺序堆叠，密集预览要简化而不是缩小，文字不小于 11px。
- **不要用一种潮流换另一种**：不以玻璃、颗粒、噪点、霓虹、bento 取代被移除的装饰；不要给每个产品套同一个外观；不改产品名（名字带 AI 也不改）；不增删功能、不编造数据与宣称。

## 六、交付前检查

- [ ] 方向五行已写，每一遍修改都遵循它
- [ ] 间距值全部落在 4px 阶梯上，同类元素同尺寸
- [ ] 图标、标签、数字各自对齐在一列
- [ ] 一条带色调的中性色阶、三档文字色、一个对比度足够的强调色
- [ ] 无色相渐变、渐变文字、发光、彩色阴影、色晕
- [ ] 界面里没有 emoji；同一套图标、同一尺寸和描边
- [ ] 字重 400–600，无大写大字距标签，无斜体强调，小字无负字距
- [ ] 无感叹号、无短文案句号、无问候标题、无未经证实的宣称
- [ ] 数字格式统一且等宽
- [ ] 嵌套圆角相加成立
- [ ] 首屏有真实视觉或带"亮点"的产品预览，没有填充物和带标记的占位框
- [ ] 首屏整体构图，没有死空白带
- [ ] 无循环或弹跳动效，一条缓动曲线，不动画布局属性
- [ ] 模板检验：换成别家产品名后界面还成立吗？成立就继续往方向上推
- [ ] 与用户已记录的偏好无冲突；有意保留的套路已在汇报中注明
